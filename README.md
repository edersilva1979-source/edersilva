# Site pessoal do Prof. & Escritor Éder Silva

Este projeto foi criado como exemplo didático para uma aula de Git e GitHub. O objetivo é mostrar como publicar um site pessoal de uma única página usando o GitHub Pages.

## Estrutura do projeto

```text
site_curriculo_eder_silva
│
├── index.html
├── style.css
├── script.js
├── curriculo_eder_silva.pdf
├── README.md
└── imagens
    └── eder_silva.png
```

## O que estamos praticando

1. Estrutura básica de HTML
2. Estilização com CSS
3. JavaScript simples
4. Links internos usando identificadores
5. Links externos para redes sociais
6. Download de arquivo PDF
7. Organização de arquivos e pastas
8. Versionamento com Git
9. Publicação com GitHub Pages

## Como visualizar no computador

Abra o arquivo `index.html` no navegador.

Para uma experiência mais próxima de um servidor web, também podemos utilizar a extensão Live Server no Visual Studio Code.

## Como publicar no GitHub Pages

1. Crie um novo repositório no GitHub.
2. Adicione todos os arquivos deste projeto ao repositório.
3. Faça os commits e envie os arquivos para a branch `main`.
4. No GitHub, abra `Settings`.
5. Acesse a opção `Pages`.
6. Em `Build and deployment`, escolha `Deploy from a branch`.
7. Selecione a branch `main` e a pasta `/ root`.
8. Salve a configuração.
9. Aguarde alguns instantes até o GitHub disponibilizar o endereço público do site.

## Links internos

O menu utiliza links como:

```html
<a href="#sobre">Sobre</a>
<a href="#experiencia">Experiência</a>
<a href="#contato">Contato</a>
```

Cada link leva até uma seção que possui o identificador correspondente:

```html
<section id="sobre">
<section id="experiencia">
<section id="contato">
```
